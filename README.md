# draw_cro


##  Description

Draw_cro challenges users to recreate a reference image by freehand drawing. It compares their sketch to the original using pixel-level analysis and returns a similarity percentage as visual feedback.


##  Tech Stack

-  React


##  Key Dependencies

```
cra-template: 1.2.0
pixelmatch: ^7.1.0
react: ^18.3.1
react-dom: ^18.3.1
react-scripts: 5.0.1
web-vitals: ^5.1.0
```

##  Run Commands

- **start**: `npm run start`
- **build**: `npm run build`
- **test**: `npm run test`
- **eject**: `npm run eject`
